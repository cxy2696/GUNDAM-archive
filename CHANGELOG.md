# Changelog

## [3.4.0] — 2026-11-16

### Changed

- Repainted the whole cockpit from phosphor green to a deep-space blue palette: navy-black backgrounds, ice-blue highlights, slate-blue bezels and blue starfields.
- Kept the operation console removed; the main display fills the viewport and the cockpit frame, header and footer carry the interface.
- Strengthened the in-display star layer and removed the fixed star canvas so stars render behind readable content without compositor conflicts.
- Converted the atlas, cockpit, graph, viewer, scope and design-sheet accents to the same blue system.

### Current snapshot

- 148 machines, 114 characters, 69 events, 82 factions, 12 eras, 156 atlas nodes.
- 1,280 static pages, 1,272 sitemap routes, 487 search entries per language.
- Version references across the site, README and docs are 3.4.0 only.
