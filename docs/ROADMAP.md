# 路线图

## 当前版本 V1.0.1（2026-11-11）

V1.0.1 是“文档与双语可用性”更新，不改变内容口径：

- 显式语言切换器：桌面头部、移动菜单、页脚；保留 path / query / hash 与滚动位置
- 根路径按已存偏好或浏览器语言选择 `/zh/` 或 `/ja/`
- 3D 仅 Stage 异步加载，页面外壳立即出现
- README 重写；新增日语 README、文档索引与 `docs:check` 链接门禁
- 修正“全部条目附出处”的表述：当前只有机体与事件强制 `sources`

## M4 的具体任务

1. **真实资产**：至少 12 台机体的 LOD0/1/2 glTF + manifest；Blender 导出脚本与 gltf-transform 流水线进 CI。
2. **内容扩量到 40 台**：B2 主线批（U.C.0079–0096 主角/宿敌），B3 谱系批（量产/衍生机）。
3. **性能**：中端安卓真机 30fps；量子形态 ≥ 常态 70%；首屏 LCP < 2.0s（4G）。
4. **视觉回归**：Playwright 截图对比，阈值 0.1%。
5. **内容可信度**：12 台机体的参数逐项核对到设定集页码，`seed` → `verified`。
6. **出处覆盖**：为势力、人物、作品、地点、标签补 `source_refs`，或在界面明确显示“以作品锚定”的覆盖范围。
7. **文档门禁**：Markdown 本地链接检查已进 CI（`pnpm docs:check`）；后续增加“文档数量/字段名”一致性检查。

## M5 的具体任务

- SEO：hreflang、canonical、sitemap、OG、结构化数据
- 监控：Sentry、Web Vitals、查看器崩溃率
- 公测：10% → 50% → 100% 灰度，观察 24h

## 风险与应对

| 风险 | 影响 | 应对 |

| 3D 资产工期 | 高 | 程序化 LOD-P 先行；资产与功能并行 |
