# 外部资料源与使用边界

> 本项目欢迎外部资料作为**检索线索与交叉校对**，不把任何 Wiki 的整页文本、数据库或图片直接复制进仓库。

## 1. 已登记的资料源

| 来源 | 用途 | 使用方式 |
| --- | --- | --- |
| [哔哩哔哩高达WIKI · 全机体资料](https://wiki.biligame.com/gundam/%E5%85%A8%E6%9C%BA%E4%BD%93%E8%B5%84%E6%96%99) | 机体名、型号、作品归属的检索入口 | 只作为线索；逐条回溯到动画/设定集/官网后重写，不复制页面文本与图片 |

## 2. 为什么没有“一键抓取全站”

- **规模**：全机体资料索引覆盖 U.C.、F.C.、A.C.、A.W.、C.C.、C.E.、A.D.、A.G.、R.C.、P.D.、A.S. 及 SD/创战/外传/游戏，条目数以千计；逐条核对参数与出处不是一次抓取能完成的。
- **版权**：Wiki 的页面编排、描述文本和图片不等同于可由本项目任意再发布的素材；官方设计图的权利归创通・Sunrise / Bandai Namco。
- **质量**：同一机体在不同作品/设定集存在口径冲突；直接抓取会把冲突固化成“事实”。

## 3. 合法接入流程

1. 在外部索引中找到目标条目，记录 URL 与作品/设定集出处。
2. 至少找到一个 S 级或两个独立 A 级来源，交叉核对型号、参数、时间。
3. 用本项目自己的中文/日文重写摘要与描述，不复制 Wiki 段落。
4. 只录入结构化事实（名称、型号、年份、阵营、参数、关系），不录入他人整理的表格。
5. 图片只使用：授权素材、自己绘制/拍摄的素材、明确可再使用的 CC 素材；在 `credit` 中写明作者、许可与来源。
6. 每批 3–5 台，附出处与校对记录提交 PR。

## 4. 图片政策

- **不收录**官方设计图、扫描设定集、模型包装图、官方渲染图或他人的二次上传。
- **不热链**外部 Wiki/图床的图片；页面不得依赖第三方图片可用性。
- 当前机体视觉是项目自绘的 **SVG 程序化图 + 程序化 LOD-P 3D**，不是官方设计图。
- 若获得授权，在 `content/asset-manifests/` 中登记 `license`、`credit`、`sourceUrl`，再接入 `image` 字段；没有授权字段的图片不得合并。

## 5. 与“全机体/全人物”的关系

当前收录 **40 台主线 Gundam 型机体、12 位人物**，覆盖 11 个纪元；不是全系列所有衍生型号与角色。全量目录需要稳定的授权数据源、逐条校对和长期维护，已列入 ROADMAP 的 B3/B4，而不是用抓取结果冒充完成。

## 6. 署名

外部索引与校对线索保留原始链接；本项目不主张对原作名称、设定、机体设计的任何权利。完整版权声明见 [NOTICE](../NOTICE)。
