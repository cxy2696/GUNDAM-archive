# 设计系统

> 视觉不是“堆发光线条”。工业科技风来自三个可执行约定：**结构可见、信息分层、克制发光**。所有 Token 定义在 `src/app/globals.css`，页面样式在 `src/styles/`。

规则：

- 大面积只用 `bg-*` 与 `text-*`；强调色不超过画面 5%。
- 发光只用于悬停分件、量子形态、危险/争议状态；常态视图不泛光。
- 关系不能只靠颜色：同时用线型（实线/虚线/点线）和文字标签。

## 2. 字体

| 角色 | 字体 | 说明 |
| --- | --- | --- |
| 展示 / 正文 | Space Grotesk + PingFang SC / Hiragino Sans / Noto Sans JP | 拉丁用 Space Grotesk，CJK 回退系统字体 |
| 数值 / 标签 | JetBrains Mono | 等宽、`font-variant-numeric: tabular-nums` |
| 字重 | 400 / 500 / 600 | 标题 500，数据 400，强调 600 |

字号阶梯：10 / 12 / 14 / 16 / 20 / 28 / 40 / 56 / 84 / 112（clamp 响应式）。
正文行高 1.65–2.0；标题行高 0.9–1.1，负字距（-0.03 ~ -0.06em）。

CJK 细节：

- 中文段落首行不强制缩进（档案卡片不适用书籍排版）；长文可开启 `text-align: justify`。
- 日文 `line-break: strict`，避免禁则字符出现在行首。
- 数值、型号统一等宽，不随语言切换改变对齐。

## 3. 布局

- 最大宽度 1500px，左右 padding 36px（移动端 20px）。
- 页面固定头部 66px；所有页面顶部有面包屑 + 章节号。
- 详情页：左 60% 查看器（sticky），右 40% 折叠卡片（`details`）。
- 断点：1280 / 1080 / 900 / 760 / 680。
- 卡片圆角 ≤ 4px；用 1px 描边和角标，不用大阴影。
- 背景网格 64px，透明度 0.22；内容区网格 8px/28px 视场景而定。

## 5. 动效

- 过渡 120–200ms，缓动 `cubic-bezier(0.22, 1, 0.36, 1)`。
- 卡片 hover：位移 ≤ 4px；查看器部件高亮：描边 + 轻微 emissive。
- 相机预设过渡 850ms，`easeInOutCubic`。
- 量子强度用帧率无关插值：`k = 1 - exp(-4 * dt)`。
- 尊重 `prefers-reduced-motion`：关闭自动旋转、待机微动、地图扫描线；保留用户主动触发的动画。

## 6. 查看器交互规格

| 交互 | 操作 | 参数 |
| --- | --- | --- |
| 旋转 | 左键拖拽 / 单指 | 阻尼 0.08，极角 ≤ 0.94π |
| 缩放 | 滚轮 / 双指 | 距离 1.2h–3.6h，平滑 |
| 平移 | 右键 / 双指 | 限制在包围盒附近 |
| 爆炸 | 滑块 0–100 | 位移 = axis × 2.4 × order × q |
| 量子 | 滑块 0–100 | 0–1 连续；粒子/环/色相/自发光同步 |
| 视角 | 正视/侧视/背视/俯视/等轴 | 850ms 过渡，交互中断 |
| 2D | 3D / 2D / 分屏 | 分屏下 hover 双向同步 |
| 静态 | 2D 模式 | 无 WebGL 也可读，满足无障碍与低端设备 |

### 语言切换

- 位置：桌面头部、移动菜单、页脚三处；不在页面正文里重复放。
- 行为：保留路径、查询串与锚点，并恢复滚动位置；不把用户送回首页。
- 标签：宽屏 `中文 / 日本語`，窄屏 `中 / 日`；每个链接有独立 `aria-label`，活动项 `aria-current="true"`。
- 首次访问：根路径按 `gundam-lang` → 浏览器语言顺序选择；不在静态 HTML 里写死中文。

键盘：所有按钮可 Tab；滑块原生可键盘调整；`Esc` 关闭抽屉/面板；`⌘K` 打开检索。

## 7. 可访问性

目标 WCAG 2.1 AA：

- 正文对比度 ≥ 4.5:1；大字 ≥ 3:1。
- 不用颜色单独传达信息；关系用线型 + 标签，状态用文字。
- 3D 查看器始终提供“设计图/静态模式”替代。
- 焦点环可见（1px cyan，offset 3px）；跳过导航链接。
- 图片/图表有 `aria-label` 或替代文本。
- 移动端触控目标 ≥ 32px；滑块为原生 input range。
- 动效遵循 reduced-motion。

## 8. 浅色主题

浅色主题采用“纸面工程图”的方向：

- 底色 `#F5F7F9`，面板白，线与文字深灰蓝。
- 量子青降饱和到 `#0E7C86`。
- 3D 舞台保持深色“视口”，与纸面 UI 形成仪器感；不强制整站反色。
- 浅色下网格透明度降低，卡片阴影改为 1px 描边。

切换逻辑：`data-theme` 写在 `<html>`，首屏脚本读取 `localStorage`，避免闪烁；默认深色，尊重用户手动选择。

## 9. 禁止事项

- 禁止大面积霓虹/泛光、玻璃拟态、彩色渐变按钮。
- 禁止圆角大于 6px 的卡片。
- 禁止用 0 表示缺失参数。
- 禁止用颜色作为唯一状态语义。
- 禁止在 3D 舞台上叠加超过三层信息。
- 禁止用官方 logo/美术作为装饰。
