# 设计系统 · v3.2 战术磷光座舱

> 视觉规则只维护在这一页。实现位置：Token 在 `src/app/globals.css`，座舱在 `src/styles/cockpit.css`，绿色磷光覆盖层在 `src/styles/tactical.css`，缩放/图谱在 `zoom.css`、`graph.css`、`atlas.css`、`era-demo.css`、`tag-map.css`。  
> 改 Token 或组件规则时，同步本页与 `docs/ARCHITECTURE.md` 的“v3.2 战术磷光座舱”一节。

## 1. 原则

1. **阅读优先**：任何装饰都不能压住正文、链接或按钮；固定层必须给内容预留空间，并允许收起。
2. **结构可见**：信息用边框、轨道、编号和分组说明“它是什么”，不靠大面积发光。
3. **磷光仪器感**：参考绿色 CRT 座舱，深色屏幕 + 墨绿边框 + 磷光绿读数；状态色不超过画面约 8%，正文始终用高对比浅绿。
4. **悬停才发光**：常态低对比，hover/focus 才提高亮度；不用颜色作为唯一语义。
5. **可维护的复用**：新页面先复用 Token 与现有组件类，不引入第二套配色或字号体系。

- CJK 行高 1.7–1.85；标题行高 0.95–1.1。

## 6. 布局与响应式

断点：`1500 / 1180 / 980 / 760 / 520`。

- **≥1760px**：显示左右 MFD 侧栏；主屏居中；侧栏与主屏错落。
- **1181–1759px**：隐藏侧栏，保留操纵台；内容占满可用宽度。
- **981–1180px**：操纵台 122px，压缩控制区；侧栏隐藏。
- **≤980px**：操纵台改为底部抽屉，右下角“打开操纵台”；头部 68px；隐藏侧栏/扫描装饰。
- **≤760px**：头部 64px，主屏边框 5px，隐藏 MFD 导轨、桌面 HUD 与装饰大字；地图/谱系/关联图内部横向滚动，页面本身不得横向溢出。
- **≤520px**：压缩头部按钮，隐藏 HUD 字号控制，保留检索、语言、主题、菜单。

页面内容宽度由 `.container` 与 `--pad` 控制；全屏缩放只作用于图表，不改变页面栅格。

## 7. 动效

- 过渡 160–380ms，缓动 `cubic-bezier(0.22, 1, 0.36, 1)`。
- 卡片 hover：上浮 2–3px；MFD 卡片轻微浮动（`glass-float` 9s）；不用大幅位移动画。
- 主屏/图表 hover 只做阴影与 ≤2px 抬升；3D 相机运动由用户触发。
- `prefers-reduced-motion` 下关闭扫描线、浮动、自动旋转与过渡；保留用户主动触发的 3D 操作。
- 打印：隐藏头部、操纵台、侧栏、HUD、背景；主屏恢复无边框/无阴影。

## 8. 可访问性

- 正文/次要文字对比度按 WCAG AA 目标；元数据不使用低于 `--text-3` 的灰。
- 交互控件必须是原生 `button` / `a`；图表节点有 `aria-label` 或 `<title>`。
- 键盘可达：`⌘K` 检索、方向键选择、`Esc` 关闭；缩放/全屏按钮有 `aria-label`。
- 3D 内容提供 2D/文本替代：地图有节点索引，关联图有文本索引，机体页有设计图。
- 不把颜色作为唯一状态：关系类型同时有线型/文字，状态同时有标签。
- 所有装饰层 `pointer-events: none`；固定 HUD 不捕获点击。

## 9. 维护规则

- 颜色/字号/间距只改 Token，不在页面里新增魔法色值。
- 新图表复用 `ZoomFrame`、`RelationGraph`、`TextZoom`，不要复制一套缩放逻辑。
- 新页面先复用 `page-head`、`section__top`、`micro`、`chip`、`btn`；确需新组件时在本文登记。
- 改外壳尺寸时同步 `--header-h`、`--console-h`、`--rail-w`，并检查移动端无横向溢出。
- 视觉回归与性能门禁尚未接入；改动后用 1440px 与 390px 截图各检查一次，并跑 `pnpm check`。
